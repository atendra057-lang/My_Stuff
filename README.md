# Atendra Maurya — Portfolio & Ventures

A portfolio website for Atendra Maurya, technology entrepreneur and founder of CodeAux and Intent.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Vanilla CSS (Tailored Design System)
- **Language**: TypeScript
- **Deployment**: Vercel / Node.js

## Features
- Clean editorial design with responsive mobile, tablet, and desktop viewports
- Selected work showcases with interactive preview video walkthroughs
- Venture spotlight for CodeAux & Intent
- Operating philosophy & leadership experience timeline

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
```
